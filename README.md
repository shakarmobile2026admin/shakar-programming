## 🔧 نصب و راه‌اندازی

### الزامات
- Python 3.10+
- PostgreSQL 12+
- Git

### مراحل نصب

```bash
# کلون کردن مخزن
git clone https://github.com/shakarmobile2026admin/shakar-programming.git
cd shakar-programming

# ایجاد محیط مجازی
python -m venv venv
source venv/bin/activate  # برای Linux/Mac
venv\Scripts\activate     # برای Windows

# نصب وابستگی‌ها
pip install -r requirements.txt

# تنظیم متغیرهای محیطی
cp .env.example .env
# ویرایش فایل .env برای تنظیم پایگاه‌داده

# ایجاد پایگاه‌داده
python src/init_db.py

# اجرای برنامه
python src/main.py
```
